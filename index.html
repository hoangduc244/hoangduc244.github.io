PROJECTS

Rover Robot

Overview: Designed and built a rover robot using an Arduino-based control system for motion, vertical lifting, and object gripping.

My Role: Programmed and integrated two encoder DC motors for driving, a stepper motor for vertical movement, and a servo motor for the gripper.

Sensors: LiDAR, camera, IMU, and GPS/camera-based localization from the ceiling.

Tools: Arduino, C++, DC Encoder Motors, Stepper Motor, Servo Motor, LiDAR, Camera, IMU, GPS

Result: Developed a functional rover platform capable of controlled movement, vertical lifting, and gripping objects using sensor-assisted navigation.

Walking Robot

Overview: Designed and built a functional walking robot using servo motors, an LCD display, and an Arduino.

My Role: Programmed motion and control using C++ and supported system integration.

Tools: Arduino, C++, Servo Motors, LCD Display

Result: Achieved stable walking motion and improved responsiveness through optimized control logic.
